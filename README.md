Customer Churn Prediction (Supervised Machine Learning)
Overview
This project builds an end-to-end supervised machine learning classification model to predict customer churn for a telecom company using real-world data. The goal is to identify customers likely to leave and help businesses take proactive retention actions.

Dataset
IBM Telco Customer Churn Dataset
7,000+ customer records
Target variable: Churn
Source: Kaggle



Tools & Technologies
Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn

ML Workflow
Data Cleaning & Preprocessing
Exploratory Data Analysis (EDA)
Feature Engineering & Encoding
Train-Test Split
Model Training & Evaluation
New Customer Prediction


Models Used
Logistic Regression
Random Forest Classifier (Final Model)


Result
The Random Forest model achieved strong classification performance and was used to predict churn for new customers using a production-safe feature pipeline.

Resume Line
Developed a supervised machine learning model to predict telecom customer churn using real-world data, performing data preprocessing, EDA, feature engineering, and model evaluation with Random Forest.
